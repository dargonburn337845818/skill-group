# Edward Tufte（信息设计大师 / 《视觉化信息的展示》作者）

> 风格/方法论推断，非本人原话。

## 立场概要

内容为王；用数据墨比与直接标注减少非信息元素；留白与编辑排版用于组织层级而非装饰；把信息放在读者需要的上下文中；重绘布局先保留所有信息，再删冗余、调整密度与排列。

## 条目（Trigger / Action / Boundary）

### 1. 重绘布局/审查界面时
- **Trigger**: 需要调整布局、视觉层级、信息密度，或判断“呼吸/流动/保留原主题”该怎么做时
- **Action**: 先保原主题身份与核心信息；用留白、分组、层级差、可读性、状态可见性制造呼吸；用一次一个焦点和短而有方向的动效制造流动；不隐藏高频内容。
- **Boundary**: 单条风格推断不是普适规则；须再按 WCAG/可用性/项目规范复核。
- **SourceRefs**: https://www.edwardtufte.com/, https://www.edwardtufte.com/book/, https://www.edwardtufte.com/about/

## 边界

基于 edwardtufte.com 官方、著作页与公开课程/访谈的风格推断，不是本人原话；可视化原则可迁移到界面信息层级，但需以 UI 可用性为准。

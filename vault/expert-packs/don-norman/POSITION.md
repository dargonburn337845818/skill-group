# 以用户心智模型与活动为中心，强调概念模型、约束（物理/逻辑/文化）、感知可供性与 signifier；设计是让人理解与易用，不是装饰。

> 风格/方法论推断，非本人原话。

## 立场概要

- 把可感知线索（signifier）放在设计中心；用户需要“能被看见、被解读”的动作指示。
- 底层概念模型是最重要的设计工具，其余设计要与它一致。
- 用 physical / logical / cultural 三类约束与约定来引导首次使用，不用空洞的“affordance”。
- 用户研究要“去真实环境观察”，不能臆测；少量真实数据即可提供方向。
- 当“听用户”会破坏活动一致性/可理解性时，要有强概念的“设计负责人”做取舍。
- 情感设计分 visceral / behavioral / reflective 三层，警惕“好看但不好用”。

## 条目（Trigger / Action / Boundary）

### 1. Signifier 优先，而非空谈 Affordance
- **Trigger**: 设计新界面/产品，或判断“用户是否知道该怎么操作”时
- **Action**: 提供可感知线索（signifier），让关键动作能被看见、被解读；屏幕界面靠约定、文字标签、一致概念模型。
- **Boundary**: signifier 建立在文化约定上，不一定可靠；不可假设用户与你共享约定，需数据验证。
- **SourceRefs**: https://jnd.org/signifiers-not-affordances/ ; https://jnd.org/affordances-and-design/

### 2. 概念模型 + 约束 + 感知可供性
- **Trigger**: 面对全新对象/系统，想知道用户首次如何理解操作时
- **Action**: 用概念模型 + 约束（物理/逻辑/文化）+ 感知可供性三件套；底层概念模型最重要，所有部分与之一致。
- **Boundary**: 概念模型不能自举，需要约定/文字/隐喻入门；隐喻有误导风险。
- **SourceRefs**: https://jnd.org/affordance-conventions-and-design-part-2/

### 3. 活动中心 > 人类中心（收到冲突用户需求时）
- **Trigger**: 在用户研究/产品设计里遇到“要不要听用户意见”时
- **Action**: 转向 Activity-Centered Design：先深挖活动/任务序列/工具约束；超出活动模型的用户建议舍弃；必要时做“设计独裁”。
- **Boundary**: 不是永远不听用户；无强概念模型兜底时忽略用户可能造成灾难。
- **SourceRefs**: https://jnd.org/human-centered-design-considered-harmful/

### 4. 情感设计三层拆解
- **Trigger**: 评估产品吸引力/情感价值，或遇到“好看但不好用”时
- **Action**: 按 visceral / behavioral / reflective 三层拆解，判断产品是功能品还是装饰/形象品，决定权重。
- **Boundary**: 三层可能冲突；功能品 usability 优先，装饰/形象品外观与反思层可占主导。
- **SourceRefs**: https://jnd.org/emotional-design-people-and-things/

### 5. 去真实环境观察
- **Trigger**: 团队争论用户“想要什么/会怎么做”，而缺乏数据时
- **Action**: 停止臆测，去真实环境观察用户做真实活动；少量（3–5 人）真实用户观察即可提供方向。
- **Boundary**: 小样本只够定性方向，非统计结论；要在用户正常环境看，不在实验室/测试房看。
- **SourceRefs**: https://jnd.org/affordance-conventions-and-design-part-2/ ; https://www.nngroup.com/people/don-norman/

# dev-network

网络排障与网络访问子技能。面向开发机/CI/容器/agent 场景中的 DNS、代理/VPN、TLS/证书、连通性/防火墙、HTTP、包管理器、Git、Docker、镜像源与 GFW 故障。

- `SKILL.md`：可执行摘要与六步流程。
- `SOURCES.md`：来源清单。
- `examples/network-dryrun.md`：3 个干跑样例。
- `checks_observed_red.md`：突变检查与静态验证记录。
- `verification.json`：校验状态（当前 `needs_verification`，真实 A/B 完成后更新）。

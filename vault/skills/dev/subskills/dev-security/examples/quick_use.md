# Quick Use：dev-security

> 一句话：信息安全子技能：威胁建模、输入校验/输出编码、认证授权、依赖与供应链、密钥/配置/日志的降险检查清单。

## 何时用

- 当任务命中 `SKILL.md` 的“触发条件 / 何时使用”时。

## 最小可复现动作

- 用户要设计/审核登录、权限、API 输入、文件上传、支付/订单、密钥存储、依赖升级。
- 用户要“安全评审这段代码/部署配置”。
- 需要把 OWASP/CWE 的抽象条目转成能直接落地的动作。
- 列出资产（数据、钱、凭据）、攻击者（外部/内部/供应链）、信任边界。

## 验证方式

- 按 `SKILL.md` 的干跑/检查清单执行；
- 发布/更新前跑 `skill_package_check.py` 与本 skill 对应校验。

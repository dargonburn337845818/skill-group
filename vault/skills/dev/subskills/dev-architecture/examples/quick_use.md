# Quick Use：dev-architecture

> 一句话：系统设计/分布式子技能：系统级架构设计、服务拆分、消息/队列、一致性模型与容量估算的可执行检查清单。

## 何时用

- 当任务命中 `SKILL.md` 的“触发条件 / 何时使用”时。

## 最小可复现动作

- 用户要设计或评审**一个系统/一组服务**的顶层架构：需求 → 约束 → 接口 → 数据流。
- 需要决定**是否拆服务、按什么边界拆、每个服务拥有什么数据与职责**。
- 需要做**消息/队列选型**：直连还是队列、至少一次/至多一次/精确一次、幂等、顺序、DLQ、背压。
- 需要选择**一致性模型**：强一致/最终一致、读写己见、事务边界、Saga/Outbox/补偿。

## 验证方式

- 按 `SKILL.md` 的干跑/检查清单执行；
- 发布/更新前跑 `skill_package_check.py` 与本 skill 对应校验。

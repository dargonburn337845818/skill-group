# skill-verification-consensus

把“我验证过了”变成有证据、可复现、可证伪的验证纪律。

| 文件 | 用途 |
|---|---|
| `SKILL.md` | Agent 可调用摘要：证据分类 + 五步验证 + 输出契约 |
| `CONSENSUS.md` | 完整版：claim class 证明表、可证伪、Skill TDD、红队、发布门槛 |
| `SOURCES.md` | 来源分级表 |
| `examples/` | 校验报告/评测场景模板 |

## 一句话

```text
可信验证 = 证据分类 + 唯一可接受证明 + 可证伪检查 + 独立复核
```

# Quick Use：value-validator

> 一句话：用语义位移、缺口重合度、编辑距离、边际收益四条硬规则判断是否继续迭代，输出 STOP/CONTINUE 与收益摘要，用于价值驱动递归提升模块的每轮收敛判定。

## 何时用

- 当任务命中 `SKILL.md` 的“触发条件 / 何时使用”时。

## 最小可复现动作

- 每轮迭代器输出新 Skill 后。
- 调度器需要决定“进入下一轮还是收敛”。
- 用户需要一份本轮收益摘要与停止原因。
- 用同一 embedding 模型对旧、新 Skill 的正文分段向量化；取逐段最近邻距离的平均。

## 验证方式

- 按 `SKILL.md` 的干跑/检查清单执行；
- 发布/更新前跑 `skill_package_check.py` 与本 skill 对应校验。

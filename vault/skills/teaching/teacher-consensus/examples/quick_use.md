# Quick Use：teacher-consensus

> 一句话：顶尖选手思路 + 信息论 → 熵减盘问、概率矩阵；让 agent 作为大师引导拆题，不直接给答案。

## 何时用

- 当任务命中 `SKILL.md` 的“触发条件 / 何时使用”时。

## 最小可复现动作

- 1. **定性共识**：顶尖选手普遍认可、可教、可模仿的解题思维原语。
- 2. **提问协议**：如何用 grill-me 式盘问，逐步降低学生对算法空间的不确定性。
- 3. **可编译知识**：每个思维原语都能转成特征问题、条件概率、方向权重，最终进入 `P(特征 | 算法)` 矩阵和熵减引擎。
- 学生拿到一道题，需要“被引导”而不是“被给答案”时。

## 验证方式

- 按 `SKILL.md` 的干跑/检查清单执行；
- 发布/更新前跑 `skill_package_check.py` 与本 skill 对应校验。

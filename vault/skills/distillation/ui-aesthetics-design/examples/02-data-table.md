# 样例 2 · 数据表格：极简反例

## 输入
一张 10 行监控数据表，被套上“极简”风格：删除所有网格线、行高 1.8、行间距 gap-8、字体 16px。

## 检查
- 密度：一屏只能看 3–4 行，用户需要频繁滚动。
- 扫描：没有表头/行间分隔，相邻行难对齐。
- 可读性：16px 并不小，但行高/间距浪费空间。

## 判断（命中规则 / 反例）
- **R7.1 少即是多，但不为空**：来源 Refactoring UI + NN/g Minimalism + Flat Design。
- **R3.1 间距尺度与密度边界**：来源 Material/Primer/Refactoring UI。
- **反例 数据密集界面不应过度留白**：数据密集界面不应过度留白。

## 改进
- 行高降到 1.4；行间距 8–12px。
- 保留表头背景/细分割线（1px `#e5e7eb`），列对齐。
- 字号 14px，数字用等宽/表格数字；表头 13px 半粗。
- 用 4/8 网格 token，不手填 20px 随意值。

## 边界
- 这不是反对极简；而是“极简不能以牺牲任务扫描为代价”。品牌展示页可以更空，但数据表优先密度。

## 可复核
- 截图同一表格改前/改后：改后一屏可视行数显著提升，且仍能看清行间分组。

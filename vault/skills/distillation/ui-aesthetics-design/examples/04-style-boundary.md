# 样例 4 · 风格边界：Editorial vs 通用数据盘

## 输入
一个数据分析后台，直接照搬“编辑杂志风”：无圆角、无阴影、单色 `#1C1C1C` + 透明度层级、衬线标题。

## 检查
- 数据视觉：单色无法表达 4 组 KPI 的语义差异。
- 可点击性：无阴影/底色后，卡片和普通文本难区分。
- 品牌风格是否适用：该后台不是作品集，而是工具型数据界面。

## 判断（命中规则 / 风格分支）
- **S8.1 锐角/无阴影为风格分支**：来源本地 editorial-style-spec + StyleKit；不是通用规则。
- **R1.3 不只靠颜色** 与 **R5.1 可点击线索**：通用底线优先。
- **反例 把品牌风格误当通用标准**。

## 改进
- 保留杂志风的标题衬线、大留白作为“品牌主题层”。
- 数据区恢复：多色语义（但附文字/形状）、紧凑表格、卡片用 1px 边框或浅背景表达层级。
- 按钮保留填充色或边框，保证可点击线索；不用“无圆角无阴影”作为全站硬规则。

## 边界
- 若用户明确要求“整站 Editorial 风格”，可全局无圆角无阴影；但必须同时说明这会牺牲数据语义/可发现性，并提供可访问替代。

## 可复核
- 同一后台切换“主题层”与“数据语义层”，对比单色与多色状态的可用性。

# 样例 6 · 从灵感站做“小窗简约大气”选型

## 输入

用户要做一个算法学习第 1 档的离线自学包 HTML：

- 小窗查看，最好 400–800px 都能用
- 简约大气，不要花
- 有轻微动效但不牺牲阅读
- 可以勾选进度、本地保存

## 选型流程（Round 36）

1. **定场景**：小窗 / 长内容 / 工具型学习页 / 非品牌展示。
2. **选站**：
   - 审美基线：land-book、siteinspire
   - 动效参考：landing.love
   - 布局模板：StyleKit `mobile-editorial` + `f-pattern-layout`
3. **提取参考卡**：
   - 色板：纸色 `#fffdf8`，墨色 `#24211f`，珊瑚色 `#e97b61`
   - 字体：衬线标题 + 无衬线正文
   - 布局：单列阅读流，顶部分栏导航，卡片纵向排列
   - 动效：滚动渐入 200–300ms，返回顶部，`prefers-reduced-motion` 时关闭
   - 小窗规则：正文 ≥15px、行高 ≥1.6、触控目标 ≥44px、不做四栏网格

## 检查命中

- **R1.1 正文对比**：`#24211f` on `#fffdf8` ≈ 15.74:1，通过。
- **R35-3 目标尺寸**：勾选框 20px 显示，实际点击区扩充到整行；按钮 ≥32px 热区；小窗建议 44px。
- **R36-5 小窗默认值**：单列 + 两列自适应，断点 480px 再收紧。
- **R35-5 动效参数**：滚动渐入 0.55s，prefers-reduced-motion 关闭。
- **R36-3 灵感不做权威**：没有照搬参考站的品牌插画/完整配色，只提取 token。

## 改进结果

- 输出 `tier1_pack_stylekit.html`：24 道题、6 个专栏、核心自问、思考方向、进度本地保存。
- 打开后小窗可读、可点击、可离线使用。

## 边界

- 这是“内容长读 + 小窗”场景的最优选型之一；如果是数据仪表盘，应改用 `corporate-clean`/`notion-style` + 紧凑网格。
- 灵感站是参考，不是权威；参考站的“炫”不能覆盖核心可访问性规则。

## 可复核

- 在浏览器 400px 宽下打开，检查：是否单列、正文是否 ≥15px、按钮是否好点、滚动渐入是否不刺眼。
- 用对比度检查器核对 `#24211f` / `#fffdf8` 与 `#e97b61` / `#fffdf8`（珊瑚色只用于非正文强调）。

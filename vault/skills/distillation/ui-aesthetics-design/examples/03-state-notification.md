# 样例 3 · 状态提示：只靠颜色反例

## 输入
表单提交后：成功显示绿色圆点，失败显示红色圆点，没有文字、图标或形状变化。

## 检查
- 只靠颜色：红绿色盲用户无法区分。
- 圆点太暗：红/绿点与白底或浅底对比可能不足 3:1。
- 没有文字说明错误原因。

## 判断（命中规则）
- **R1.3 不只靠颜色**：来源 NN/g Visual Treatments + Primer Color Accessibility。
- **R1.2 非文本对比 ≥3:1**：来源 WCAG 1.4.11 + Primer。
- **反例 只靠颜色区分状态**。

## 改进
- 成功：绿色圆点 + “✓ 已保存” 文字；失败：红色图标 + “保存失败，请重试” 文字。
- 圆点/图标与背景 ≥3:1；颜色不是唯一信号。
- 若为图表分类，可加形状（圆/方/三角）或图案。

## 边界
- 纯装饰色可自由用；如果用户群明确无视觉障碍且信息不影响任务，可放宽，但工具/表单仍应保留非颜色线索。

## 可复核
- 打开色弱模拟/灰度截图：改进后仍能区分成功/失败。

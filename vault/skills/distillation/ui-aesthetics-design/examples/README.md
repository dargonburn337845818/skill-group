## 怎么用

1. 从 `SKILL.md` 加载三步流程与检查清单。
2. 遇到类似界面，先对照对应样例的“问题”做检查。
3. 参照“改进”给出具体数值；看到“边界”时判断该建议是否适用于当前场景。

## 复核方式

- 用在线对比度检查器核对改进色值。
- 对数据表/状态提示做截图或灰度/色弱模拟。
- 每个样例的命中规则、来源与边界都可回到 `CONSENSUS.md` 和 `SOURCES.md` 复核。

> 过程性审计材料在 `audit/`，不进入本用户样例文档。

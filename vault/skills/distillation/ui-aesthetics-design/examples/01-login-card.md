# 样例 1 · 登录卡片改进

## 输入
一个登录卡片：白色背景，标签 12px 灰色 `#999`，输入框无 focus 样式，唯一按钮“登录”是灰色文字链接样式。

## 检查
- 对比度：`#999` on white ≈ 2.85:1 → 不通过。
- 字号：标签 12px，低于核心正文建议 → 不通过。
- 控件：按钮看起来像链接，可点击线索弱；输入框无 focus → 不通过。

## 判断（命中规则）
- **R1.1 正文对比度 ≥4.5:1**：来源 WCAG 1.4.3。
- **R2.1 正文 16px/24px、≥14px**：来源 Tailwind/GOV.UK/Material/Primer。
- **R6.1 焦点可见**：来源 WCAG 2.4.7 + NN/g。
- **R5.1 可点击线索**：来源 NN/g Clickable Elements。

## 改进
- 标签与正文用 `#1F2937`/白底，对比 ≥7:1；字号 14px。
- 输入框 border 1px、focus 加 2px 外环（状态间 ≥3:1）。
- 主按钮：实心底色、`padding 12px 24px`、白字 ≥4.5:1；占满表单主路径。

## 边界
- 如果这是品牌艺术登录页且用户明确要极简，可弱化按钮底色，但必须保留至少一种可点击线索；不能把标签降到 12px 灰色承载关键操作。

## 可复核
- 用在线对比检查器测改进后的颜色；截图查看 focus 环。

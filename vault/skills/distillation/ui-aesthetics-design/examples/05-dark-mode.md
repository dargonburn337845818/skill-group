# 样例 5 · 深色模式验证

## 输入
一个表单页：浅色模式正文 `#333` 通过对比度；切到深色模式后，文字仍是深色 `#333`，背景变深蓝，几乎不可读。

## 检查
- 浅色模式通过 ≠ 深色模式通过。
- 深色模式下正文/背景对比是否 ≥4.5:1。
- 是否使用语义 token 还是硬编码色值。

## 判断（命中规则 / 来源）
- **R1.4 双主题验证**：来源 Apple Sufficient Contrast Evaluation Criteria。
- **R2.1 字号/行高 + 语义 token**：来源 Tailwind/GOV.UK/Material/Primer。
- **R1.1 正文对比度 ≥4.5:1**：来源 WCAG 1.4.3。

## 改进
- 使用 `--fg` / `--bg` / `--muted` token；切主题时一并切换。
- 暗色下正文 `#E5E7EB` 或 `#D1D5DB`，背景 `#111827`，重测对比度 ≥4.5:1。
- 边框/焦点环也用 token，确保暗色下 ≥3:1。

## 边界
- 若产品不支持暗色模式，此条跳过；一旦支持，必须测两套主题。

## 可复核
- 浏览器 DevTools 模拟 dark 模式，或截图对比两套主题的 contrast checker 结果。

NVIDIA 调优工具 —— 具体优化了哪些
====================================

一、本地设置一键优化（LocalOptimizer）
--------------------------------------
1. 电源计划
   - 备份当前电源方案 GUID；
   - 切换到“高性能”或复制当前方案生成优化副本；
   - 插电时：CPU 最小 5%、最大 100%，磁盘不休眠，USB 选择性挂起关闭。
   - 可逆：回滚时恢复原电源方案。

2. WSL2 配置
   - 备份 %USERPROFILE%\.wslconfig；
   - 写入 memory=10GB / processors=12 / swap=4GB；
   - 默认不自动执行 wsl --shutdown，避免打断正在运行的 WSL。
   - 可逆：回滚恢复原文件；原本没有则删除。

3. 游戏相关注册表
   - GameDVR_Enabled = 0（关闭系统录屏）；
   - AutoGameModeEnabled = 1（开启 Windows 游戏模式）；
   - 可逆：回滚导入原注册表导出。

4. 不做的事
   - 不碰 BIOS/EC、不装驱动、不超频；
   - 默认不开启硬件加速 GPU 调度（HAGS）。

二、G-Helper 智能调度（Scheduler）
----------------------------------
- 根据 GPU 利用率 / CPU 负载 / 温度 / 重负载进程自动切换：
  空闲 -> Silent
  日常 -> Balanced
  游戏/AI/高负载 -> Turbo（或 Custom1）
  温度 > 88 C -> Turbo
- 带 30/60 秒持续确认 + 120 秒最小切换间隔，防抖。
- 不超频，只切换 BIOS 预设档 + 你在 G-Helper 里配好的风扇/功耗策略。
- 反馈：D:\<工具目录>\查看状态.bat 或面板“刷新状态”显示当前档位/GPU/温度/进程。

三、内存调度（已纳入自动调度）
--------------------------------
- GHelperSmartScheduler 现在也会监控 Windows 内存占用；
- 触发规则：
  - 内存占用 >= 80%：自动调用 Mem Reduct 清理；
  - 即将进入重负载且内存 >= 60%：先清理一次再切高性能档；
  - 两次清理之间默认冷却 10 分钟，防止频繁清；
- 调用命令：memreduct.exe /clean:0x67；
- 需要调度器以管理员运行才真正生效；若未提权，日志会记录“跳过”；
- 配置项都在 optimizer\GHelperSmartScheduler.config.json。

三、Mem Reduct 配合
------------------
- 你现有 D:\<内存工具目录>\Mem Reduct\memreduct.exe；
- 支持命令行：memreduct.exe /clean:0x67（默认组合清理）；
- 本工具“清理内存 Mem Reduct”按钮会以管理员调用它；
- 建议：跑大型 AI 训练前手动清理一次即可，不需要频繁清理。

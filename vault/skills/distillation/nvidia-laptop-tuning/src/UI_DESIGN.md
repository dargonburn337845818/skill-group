# UI 设计契约 —— NVIDIA 调优面板（StyleKit Sketch Style）

> 版本：0.5.0
> 来源：https://www.stylekit.top/zh/styles/sketch-style
> 目标：铅笔手绘风 / 纸张质感 / 参数图形化 / 交互短促直接。

## 核心规则
- 背景纸张米色：`#F5F0E8`；卡片浅纸色：`#FDF9F1`。
- 主色铅笔灰：`#2C2C2C`；辅助灰：`#6B6B6B`。
- 强调色（低饱和）：红 `#E74C3C`、蓝 `#3498DB`、绿 `#27AE60`、黄 `#F39C12`。
- 边框：2px 虚线/不规则手绘线；禁用完美直线/纯白背景/渐变/玻璃模糊/长时间平滑动画。
- 字体：标题/正文/按钮使用 `KaiTi`（楷体手写感）；图标用 Segoe MDL2。
- 阴影：交叉线（cross-hatch）替代纯色阴影；元素可轻微倾斜。
- hover：短促“铅笔涂黑”反馈；active：按压感（更暗 + 轻微位移/抖动）。

## 图形化
- 实时趋势图：GPU/CPU/内存/温度/功耗 5 条序列，纸张底 + 虚线边框 + 图例。
- 刷新：后台线程更新，UI 不阻塞；图表滚动保留最近 120 点。

## 禁区
- 不使用完美圆角/现代渐变/科技发光；不使用模板化彩色卡片。
- 不新增磁盘/网络控制；磁盘/网络只观测。

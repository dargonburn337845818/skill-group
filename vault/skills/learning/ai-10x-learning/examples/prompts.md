# 6 个高杠杆学习提示词（二手编译，来源见 SOURCES.md）

> 用法：把 `[主题]` 替换成具体学习对象。这些不是 Dan Koe 播客逐字稿内容，而是 Rahul 同名 X 博文的中文编译，作为“可复制工具包”使用。

## 1. 学习阶梯

```
我想要一步一步学习[主题]，不跳过任何重要的基础知识。
请扮演一位专业的教师和技能教练。将[主题]分解为5个清晰的难度等级，
从完全初学者到自信的实践者。对于每个等级，包含：
1. 等级名称
2. 此阶段我应该理解什么
3. 精通表现
4. 最重要的概念或技能
5. 证明我准备好进入下一级的里程碑
6. 一个动手练习或小项目
7. 学习者常犯错误
8. 进入下一级之前的一个简单自测问题
等级：完全初学者 / 基础理解 / 实际应用者 / 问题解决者 / 自信的实践者
```

## 2. 20 小时计划

```
我想在20个专注的小时内学会[主题]。
请扮演专业教师和学习策略师：
1. 找出能带来80%实际效果的20%概念/技能/原则。
2. 解释这些核心领域为什么重要。
3. 制定10次课，每次2小时；每次课含目标、关键概念、练习/小项目、免费资源、预期成果。
4. 每次课后给5个复习问题。
5. 全部结束后建议一个能证明理解并能在实际中应用的最终项目。
```

## 3. 考官循环（主动回忆）

```
我刚刚学完了[主题]，请扮演严格但有帮助的考官。
一次只问一个问题，共10题，难度逐渐增加（1-3初级/4-6中级/7-8高级/9-10专家）。
每个回答后：打10分制、说明哪里对、找出确切漏洞、用简单语言只重讲错的部分。
回答弱则追问一个跟进问题；回答好则略提高难度。
最后给出：最终得分、最强/最弱领域、简短复习计划、5个终极挑战问题。
不要一次性给答案，要像真正的学习面试。
```

## 4. 一页纸小抄

```
给我一份关于[主题]的一页纸备忘单，能在使用前5分钟快速浏览。
包含：简短定义、最重要概念/规则/公式/步骤、要点而非长段落、可选的图表/流程图/表格、
3-5个现实例子、应避免的常见错误、使用前快速检查清单、5个快速记忆测试题。
```

## 5. 资源策展（信号 > 噪音）

```
我想快速学会[主题]，但不想在低质量资源上浪费时间。
请扮演学习策展人，找出5个杠杆最高的资源（书/视频/课程/网站/社区/专家）。
每个资源给：名称、类型、为什么值得、帮我学哪个具体部分、适合哪类学习者、
难度等级、如何有效使用、一个关于不要浪费时间的警告；按最佳使用顺序排列。
最后给一个只用这些资源的7天学习路径。
```

## 6. 费曼循环

```
我想用费曼学习法深入理解[主题]。
先用简单语言向我解释，像对12岁小孩：简单词汇、现实例子、类比、无必要术语、简短讲解。
讲解完后让我用自己的话复述。
然后检查我的复述：指出正确的部分、找出所有漏洞/错误/混淆/遗漏、
只重讲我错或漏的部分、让我再解释一遍，循环到简单准确完整。
规则：解释清晰前不前进；不灌输额外理论；温和清晰纠正；困惑时用例子。
最后给我一份可保存的最终简洁解释。
```

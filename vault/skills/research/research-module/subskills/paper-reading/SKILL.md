# 论文阅读 · Paper Reading

## 触发

- 用户给出论文 PDF / URL / 全文 / 摘要，说“帮我读这篇/总结这篇/理解这篇”。
- 用户需要快速判断论文在领域中的位置，或准备组会阅读。

## 动作

1. **先做领域识别**：读 `vault/meta/domain-profiles.json`，命中科研/物理/可见光等关键词时加载对应导师团。
2. **读取领域共识**：若论文属于 VLPC/物理信息类，先读 `vault/skills/research/vlpc-consensus/VLPC教师共识.md`。
3. **按导师分工读**（每位导师输出一条“这篇论文我看什么”）：
   - Ting Yang（系统架构）：整体信号拆分、DC/AC 职责、与已有系统差异；
   - Ping Wang（定位/信号处理）：定位链路、抗噪、指纹库、精度规律；
   - S. Ma（波形设计）：波形/功率分配、通信性能、能效；
   - Y. Chen（实验）：实验设置、误差来源、可复现性；
   - 用户指定/添加的其他导师按同格式补充。
4. **产出论文卡**：

```text
一句话定位
问题（现有方法缺什么）
方法（核心思路，不是公式搬运）
关键结果（数字 + 趋势）
局限（哪些地方未回答）
可讨论点（给组会留 1–2 个钩子）
```

5. **每个结论标注**：`【expert_name · 领域】` + sourceRefs；区分“原文”与“我的推断”。

## 边界

- 不替代论文原文：涉及公式、实验数字、引用编号时回到原文核对。
- 不编造作者原话：把论文内容转成“推断整理”。
- 若论文不在现有导师覆盖范围，先标“该领域暂无 ready 人名专家”，再按专家缺口分支处理。
- 一次只问一个高信息增益问题，不要同时抛一串术语。

# 文献脉络 / 研究方向 · Paper Outline

## 触发

- “这个方向还有哪些路”“帮我理一下领域脉络”“我想找研究方向/选题”。
- 需要从几篇论文中归纳出问题谱系，而不是单篇总结。

## 动作

1. **收集材料**：列出用户已有论文/综述/笔记；不足时调用 `search-source` 底座补充可追溯来源。
2. **按导师视角分线**（每条线标注导师姓名）：
   - 系统架构线（Ting Yang）：系统形态、信号分工、一体化方案；
   - 算法/信号处理线（Ping Wang）：定位抗噪、指纹库、通信解码；
   - 波形/资源分配线（S. Ma）：功率分配、波形优化、能效；
   - 实验/落地线（Y. Chen）：实验平台、误差、可复现性；
   - 物理直觉线（Richard Feynman，待蒸馏）：先做最简单情形、检查量纲与极限。
3. **输出三件套**：
   - 领域地图：现有工作按问题/方法聚类；
   - 开放问题表：问题 / 为什么重要 / 已有人做到哪 / 缺口；
   - 候选方向：每个方向给 1–2 条可验证的下一步，并标注建议者。
4. **冲突保留**：不同导师对同一个方向看法不同，不平均，保留分支并记录分歧。

## 边界

- 所有文献关系必须有来源；不确定的标 `common-lore` 并降权。
- 候选方向不等于确定可行，必须说明假设和验证方式。
- 不为了“看起来完整”硬造导师意见；没有 ready 专家就按缺口分支处理。

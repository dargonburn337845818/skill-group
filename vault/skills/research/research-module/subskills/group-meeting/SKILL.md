# 组会 · Group Meeting

## 触发

- 用户要准备一次组会报告、模拟组会问答、写口述稿或 6 页模板。
- “帮我练一下组会”“导师可能会问什么”。

## 动作

1. **读取组会共识**：`vault/skills/research/vlpc-consensus/组会报告技巧共识.md`。
2. **按内容公式搭骨架**：

```text
动机（为什么重要）
+ 问题（解决什么）
+ 方法（核心思路）
+ 结果（关键数字/趋势）
+ 局限与讨论
```

3. **准备 3–5 个模拟提问**，每个问题标注提问导师：
   - Ting Yang：系统级取舍、为什么这样设计；
   - Ping Wang：定位精度、抗噪、实验误差来源；
   - S. Ma：功耗/速率/能效、参数选择；
   - Y. Chen：实验设置、可比性、可复现性。
4. **逐轮模拟**：
   - 导师问一个问题（只问一个）；
   - 你先答；
   - agent 再补充“论文哪里支撑 / 这是推测”。
5. **输出问答表**：问题 / 提问导师 / 你的答案 / 论文证据 / 待确认项。

## 边界

- 组会模板是参考不是枷锁，用户可要求偏离。
- 模拟提问不是真实导师意见；不能代替真人反馈。
- 不会答时不要编，留“会后查证”占位。
- 若该领域无 ready 导师团，问用户“蒸馏专家团 / 直接用大模型”，不静默降级。
